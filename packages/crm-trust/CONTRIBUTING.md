# Contributing

Preserve the audit's read-only and evidence-first boundaries.

- Keep deterministic fetching, measurement, validation, and score arithmetic
  in code; keep interpretation in isolated, schema-checked agent tasks.
- Add a synthetic fixture and regression test for new signals, rules, safety
  behavior, or report contracts.
- Do not add HubSpot write endpoints, raw-record prompts, or credentials to
  examples and tests.
- Run `pytest` from this directory before opening a pull request.
- Keep existing-deal exposure separate from no-deal recoverable populations.
- Any final-gate change needs a negative regression test proving a dangerous
  phrase cannot be cleared outside its designated safety section.
