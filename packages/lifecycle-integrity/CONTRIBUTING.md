# Contributing

Preserve the lifecycle audit's read-only, journey-first, and evidence-first
boundaries.

- Keep deterministic fetching, journey confidence arithmetic, measurements,
  scoring, validation, and report rendering in code.
- Keep journey interpretation and recommendation phrasing in isolated,
  schema-checked agent tasks.
- Add a synthetic fixture and regression test for new motion signals, leakage
  rules, safety behavior, or report contracts.
- Do not add HubSpot write endpoints, raw-record prompts, or credentials to
  examples and tests.
- Run `pytest` from this directory before opening a pull request.
- Keep existing deal exposure separate from no-deal recoverable populations;
  never invent an amount for a lead without a deal.
