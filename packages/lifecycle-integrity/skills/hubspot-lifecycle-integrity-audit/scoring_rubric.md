# Scoring rubric

## Integrity dimensions

| Dimension | Points |
|---|---:|
| Lifecycle integrity | 20 |
| Association integrity | 20 |
| Handoff integrity | 20 |
| Attribution continuity | 20 |
| State coherence | 10 |
| Property governance | 10 |

Journey mapping confidence is reported separately and is never folded into the
integrity score.

## Ownership

Deterministic code calculates all dimension, journey-pattern, and overall
scores. The LLM may interpret, explain, or recommend; it must not alter score
arithmetic. Findings count only after adjudication as approved or revised.

If a journey is medium confidence, cap or downgrade high-severity conclusions
unless the finding has independent evidence. Low-confidence journeys can only
produce observations.
